# Materiais da Intervenção Pedagógica

Este repositório reúne os materiais utilizados na intervenção pedagógica
desenvolvida no âmbito da pesquisa sobre o ensino de lógica de programação
por meio do desenvolvimento web, em articulação com a habilidade EF07CO11
da BNCC da Computação.

## Organização

- `documentos/` – documentos relacionados à realização da intervenção;
- `planos-aula/` – planos e materiais dos encontros;
- `questionarios/` – instrumentos utilizados para coleta de dados.

## Materiais

Os arquivos disponibilizados neste repositório correspondem aos materiais
elaborados e utilizados durante a intervenção pedagógica.
